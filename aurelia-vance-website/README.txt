HOW TO RUN
1. Keep every file in this folder exactly as it is (do not move files into other folders).
2. Put your hero video inside the "video" folder and name it hero.mp4  (see video/PUT-VIDEO-HERE.txt).
3. Open index.html in Chrome, Edge or Safari.

Pages: index.html (home), property.html, area.html, calculator.html
To change the video file names, edit the HERO line at the top of the video block in home.js.
